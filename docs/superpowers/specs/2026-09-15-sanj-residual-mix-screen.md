# SANJ Residual Mix Screen

## Hypothesis and gate

The accepted N7 residual improved the policy parent at `EvalMix=10`, while a
20% mix was previously neutral-negative. Test the single midpoint candidate,
15%, against the frozen 10% hybrid using the same H3o binary, network, policy,
openings, and 20,000-node budget for 128 paired games. Reject on a negative
point estimate or any anomaly. Only a pass permits a separate 256-game Blunder
7.6 screen; no further mix value is selected from the same openings.

## Outcome

The clean 128-game screen scored 36/39/53 (48.83%,
`-8.14 +/-46.33 Elo`) for the 15% candidate. It failed the registered
point-estimate floor, so no Blunder games ran. The tested 10% residual remains
the selected hybrid setting.
